# Gestão — Kanban Tasks

> Painel via Tasks plugin. Para visão Kanban arrastável, instale o plugin Kanban e aponte para esta pasta — as tasks abaixo já são compatíveis.

## A fazer
```tasks
not done
path includes DevMock Cerebro
sort by priority
limit 50
```

## Por fase
```tasks
not done
group by filename
sort by priority
limit 50
```

## Concluídas (auditoria)
```tasks
done
sort by done reverse
limit 20
```
