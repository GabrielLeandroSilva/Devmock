# Gestão — Project Charter

## 1. Objetivo
Formalizar escopo, público, princípios e governança do DevMock para que Fases 1–5 tenham uma referência única de decisão.

## 2. Detalhamento
- **Produto:** API Contract & Mocking para Front-end — *"Build your frontend without waiting for the backend."*
- **Público MVP:** devs Front-end/Full Stack, times pequenos, APIs REST (React/Vue/Angular/Svelte).
- **Primeira entrega:** VS Code Extension sobre DevMock Core TS (§3 do original). CLI/CI pós-MVP.
- **Princípios (§33):** Schema First, Zero Backend Dependency, Realistic Data, Reproducible (seed), Git Friendly, Developer Friendly, Progressive Complexity.
- **Governança docs:** vault `DevMock Cerebro`, trabalho em `des`, `main` só via PR aprovado; versões `v0.x` por fase, `v1.0.0` no MVP validado.
- **Agentes:** Arquiteto (estrutura), PRD-Writer (escopo), Coder-TS (implementação futura), Git Guardião (versionamento).
