# Extras — 03 Posicionamento e GTM (§32)

## Nome e descrição
**DevMock** — *API Contract & Mocking for Front-end.*

## Slogans candidatos
1. *Build your frontend without waiting for the backend.* (principal — direto na dor)
2. *Design the contract. Mock the API. Build before the backend.* (fluxo)
3. *Turn an API contract into a complete development environment.* (visão)

## Posicionamento
Não é "API falsa": é **camada de API Contract Development** entre front e backend. Público inicial: front-end solo e times pequenos BR (diferencial dos geradores locais).

## GTM MVP (quando o código existir)
1. Publicar na VS Code Marketplace (grátis) + README com GIF de 30s (Init → GET 200).
2. Exemplos com dados BR (CPF/PIX/CEP) como vitrine.
3. Lançar em comunidades BR (He4rt, front-end groups) pedindo feedback, não estrelas.
